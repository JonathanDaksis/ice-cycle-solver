        2 · Otto cycle spark ignition

        1–2Isentropic compression

        Q12 = 0T2 = T1rk−1P2 = P1rk

        2–3Constant-volume heat addition

        V2 = V3W23 = 0Qin = mcv(T3 − T2)

        3–4Isentropic expansion (power stroke)

        Q34 = 0T4 = T3/rk−1P4 = P3/rk

        4–1Constant-volume heat rejection

        V4 = V1Qout = mcv(T4 − T1)
        r = V1/V2 = V4/V3
        wnet = qin − qout = cv[(T3 − T2) − (T4 − T1)]
        η = 1 − Qout/Qin = 1 − (T4 − T1)/(T3 − T2)
        ηOtto = 1 − 1/rk−1

        Efficiency depends only on r and k. Raising the compression ratio raises the ideal efficiency.

        3 · Diesel cycle compression ignition

        1–2Isentropic compression

        T2 = T1rk−1P2 = P1rk

        2–3Constant-pressure heat addition

        P2 = P3Qin = mcp(T3 − T2)T3/T2 = V3/V2

        3–4Isentropic expansion

        T4 = T3(rc/r)k−1P4 = P3(rc/r)k

        4–1Constant-volume heat rejection

        V4 = V1Qout = mcv(T4 − T1)
        r = V1/V2rc = V3/V2 = T3/T2
        qin = cp(T3 − T2) = cpT2(rc − 1)V4/V3 = r/rc
        wnet = cp(T3 − T2) − cv(T4 − T1)
        η = 1 − cv(T4 − T1)/[cp(T3 − T2)]
        ηDiesel = 1 − (1/rk−1) · (rck − 1)/[k(rc − 1)]

        At the same r, the ideal Otto cycle is more efficient than the Diesel cycle whenever rc > 1.
